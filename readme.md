
# 📄 HTML Demo Website

Welcome to the HTML Demo Website — a clean and simple example website built to demonstrate foundational web‑development skills using HTML and CSS and Bootstrap Framework.  
Live version: [https://kamrulshawn2003.github.io/html-demo-website/](https://kamrulshawn2003.github.io/html-demo-website/)

---

## 🧰 Technologies Used

- HTML5 – semantic structure and markup  
- CSS3 – styling, layout and responsive design  
- Bootstrap Framework 

---

## ✨ Features

- Simple, elegant layout demonstrating core web‑design principles  
- Sections for header, content, footer (or whatever structure)  
- Fully responsive across devices  
- Easily extendable and modifiable for learning or beginner projects

## 🚀 How to Use

1. Clone the repository  
   ```bash
   git clone https://github.com/kamrulshawn2003/html-demo-website.git
````

2. Navigate into the project folder

   ```bash
   cd html-demo-website
   ```
3. Open `index.html` in your browser
4. Modify HTML, CSS, or JS files to customize or learn
